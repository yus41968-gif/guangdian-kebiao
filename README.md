# 信息学院硕士研究生课表（2026～2027学年第一学期）

在线地址：**https://yus41968-gif.github.io/guangdian-kebiao/**
（GitHub Pages 永久托管，不需要任何本地电脑开机）

## 功能

- 6 个专业课表切换（默认：电子信息（光电信息工程），选择会被浏览器记住）
  - 电子信息（光电信息工程）、光学工程、控制科学与工程、电子信息（计算机技术）、电子信息（控制工程）、电子信息（通信工程）
- 按**真实时间轴**的周历：午休/晚休间隔留出，课程卡片高度=实际时长
- 周次切换（第1～19周）＋"本周"按钮，自动定位当前教学周
- 本周课程明细表、学期课程总览表；点击课程块/表格行查看详情
- 支持手机：可"添加到主屏幕"当 App 用（PWA），打开过一次后离线也能看

## 文件说明

| 文件 | 说明 |
|---|---|
| `index.html` | 页面结构（引用的 css/js 带 `?v=N` 版本号，用于刷新缓存） |

## 数据来源与维护

- 来源：《信息学院-2026～2027学年第一学期硕士研究生专业课程表.pdf》（6 页，每专业一页）
- 教学周第 2～17 周，2026 年 9 月 7 日（第 2 周）起使用；个别课程标注至第 18/19 周（含补课/单双周）
- 合并单元格的解析依据：单元格坐标几何 ＋ "周节数 × 周数 = 总学时" 交叉校验；遇到含糊处按 PDF 原表标注优先

### 更新流程（改课/换学期）

1. 编辑 `schedule-data.js`（新增条目用 `E(星期, 起节, 止节, 课程名, 类别, 学时, 教师, 教室, 周次数组, 周次文字, 是否形成性评价, 是否任选)`）
2. 把 `index.html` 里的 `?v=4` 提升为 `?v=5`（共 3 处），并把 `sw.js` 的 `VERSION` 改为 `kb-v5`
3. 提交/上传到仓库，GitHub Pages 约 30 秒后自动生效
4. 本地自检脚本（可选）：`node .tmp/check_all_majors.js`、`node .tmp/smoke_test.js`
